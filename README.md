#### How I work

- Start from a real problem and a short written spec, then get a working version in front of people quickly.
- Build with AI coding agents (mostly Claude Code) and keep the human parts human: deciding what to build, judging quality and talking to users.
- Be honest about the state of things: every README above has a "status and limitations" section.
